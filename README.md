# 工場稼働管理アプリ

丸編み工場（機械50台・多機種混在）の稼働状況を、マネージャーがスマートフォンで手軽に確認・更新するためのツールです。

ビルド不要の単一 HTML ファイル（`index.html`）で構成されており、無料で運用できます。

## 使い方

- **ローカルで開く**: `index.html` をモバイルブラウザ（またはPCブラウザ）で開くだけで動作します。
- **ホスティングする場合**: GitHub Pages などの静的ホスティングにそのまま配置できます（サーバー・ビルド不要）。
  - GitHub Pages: リポジトリの Settings → Pages でブランチを指定すると `https://<user>.github.io/<repo>/` で公開されます。

## iPhoneのホーム画面に追加する

1. 上記のURL（GitHub Pagesなど、`https://`で始まるもの）を **Safari** で開く
   - `file://` で開いたローカルファイルは正しく追加できない場合があるため、必ずWeb上のURLを使用してください
2. 画面下部の共有ボタン（□に↑のアイコン）をタップ
3. 「ホーム画面に追加」を選択 → 名前を確認して「追加」
4. ホーム画面のアイコンから起動すると、Safariのアドレスバーなしでアプリのように全画面表示されます

アイコン（`apple-touch-icon.png` 等）とアプリ名はあらかじめ設定済みのため、追加するだけですぐに使えます。

## 機能

- **サマリー表示**: 平均稼働率／稼働中台数・全台数／今週（7日以内）の段取り予定件数
- **機械一覧**: カード形式（号機番号の自然順ソート）。号機・機種・状態（色分け＋ラベル）・現在品番・稼働率・次回段取りまでの日数・メモを表示
- **検索・フィルター**: 号機／品番／機種のキーワード検索、状態（稼働中・段取り中・停止・計画停止）チップによる絞り込み
- **登録・編集・削除**: カードタップで編集シートを開く。削除は誤操作防止のため編集シート内に配置
- **一括登録**: 台数と号機の接頭辞を指定してまとめて作成（初期状態は「計画停止」、既存号機の続き番号から採番）
- **データ永続化**: ブラウザの `localStorage` に保存。保存・読み込みに失敗した場合はエラートーストで通知
- **ダークモード対応**: 端末の設定に自動追従

## データについて

- データは**端末のブラウザ内（localStorage）**に保存されます。アプリを閉じても消えませんが、端末・ブラウザをまたいだ共有はされません。
- 保存キー: `factory-machines-v1`
- 複数端末での共有や既存の Notion／GAS 基盤との連携が必要になった場合は、保存処理（`loadMachines` / `saveMachines`）を差し替えることで対応できます（例: GAS 製 API、Firebase など）。

## データモデル

| フィールド | 型 | 説明 |
|---|---|---|
| `id` | string | 一意のID（自動生成） |
| `no` | string | 号機番号（例: "01"） |
| `model` | string | 機種名（任意） |
| `status` | enum | `running`（稼働中）/ `changeover`（段取り中）/ `stopped`（停止）/ `idle`（計画停止） |
| `sku` | string | 現在の品番 |
| `uptime` | number | 稼働率（0〜100の整数、%） |
| `nextChange` | string | 次回段取り予定日（YYYY-MM-DD） |
| `note` | string | メモ（任意） |
